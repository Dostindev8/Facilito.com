## Cabeceras y CORS

Web (`middleware.ts` + `next.config.ts`): CSP con nonce y `strict-dynamic` (enforce), HSTS en producción, `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy`, `Permissions-Policy` (cámara, micrófono, geolocalización, pago y USB cerrados), COOP.
API (helmet + `@fastify/cors`): CSP `default-src 'none'`, CORP same-origin, HSTS en producción, `Referrer-Policy: no-referrer`, CORS con allowlist (`CORS_ORIGINS`) y credenciales; origen no listado no recibe `Access-Control-Allow-Origin` (prueba en `auth.int.test.ts`).
